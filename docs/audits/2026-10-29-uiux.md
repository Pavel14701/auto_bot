Аудит полного фронтенда `frontend/src` (мини-апп + партнёрский ЛК) по коду, без живого
браузера. Основа: токены `frontend/src/index.css`, доки `docs/NAV-V2.md`, `docs/UIUX-GEO.md`.
Все ссылки `файл:строка` — фактические, из текущего кода.

Пройденные экраны: Landing, Shell/таб-бар, Home (Лента|AI), Feed (чипсы/шит/карточки/скелетоны),
Listing PDP (галерея/осмотр/чек/история/CTA/sticky-бар), AiSearch, Favorites, Analyses (История),
MyLotsPanel, SellCar (3 шага + edit + FAB), Calc, Compare, Filters (Сигналы), Chats (список/

**Общая оценка UX: 7/10.** Зрелая, дисциплинированная база (состояния, токены, касания, копирайт).

а сам Calc захардкодил корейский маршрут; (2) хвосты NAV-V2 — после публикации объявления
пользователь выбрасывается в Профиль, где «Моих объявлений» больше нет.
